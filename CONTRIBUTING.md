# Participated in the development of TRIGRIX Studio

TRIGRIX Studio is an open source project. Proposals, corrections, new blocks,
Generators and documentation improvements are welcome.

1. Create a separate branch to change.
2. Do not add tokens, Chat ID and other secrets.
3. Add or update tests.
4. Run `pytest` and attach a description of the test scenario.
5. Pass the change through https://github.com/TRIGRIX/trigrix-studio.
